\# ONG Mãos Solidárias



Projeto web desenvolvido para a ONG Mãos Solidárias, com o objetivo de apresentar a organização, seus projetos e possibilitar o cadastro de pessoas interessadas em atuar como voluntárias.



\## Tecnologias utilizadas



\* HTML5

\* CSS3

\* JavaScript

\* Git

\* GitHub



\## Estrutura do projeto



```text

ong-maos-solidarias/

├── html/

│   └── index.html

├── css/

│   └── style.css

├── imagens/

│   └── ong.jpg

├── js/

│   └── script.js

├── cadastro.html

├── projetos.html

└── README.md

```



\## Funcionalidades



\* Navegação entre as páginas do projeto

\* Menu responsivo para dispositivos móveis

\* Área de projetos da ONG

\* Página de cadastro de voluntários

\* Validação de campos do formulário

\* Máscaras para dados do formulário

\* Navegação dinâmica utilizando JavaScript

\* Recursos de acessibilidade no menu



\## Acessibilidade



O projeto utiliza recursos de acessibilidade para facilitar a navegação, incluindo estrutura semântica em HTML e identificação adequada dos elementos interativos.



O botão do menu mobile possui `aria-label`, permitindo que leitores de tela identifiquem sua função.



\## Versionamento



O projeto utiliza Git e GitHub para controle de versão.



Foi utilizado o padrão de mensagens de commit, como:



\* `feat:` para novas funcionalidades

\* `fix:` para correções

\* `docs:` para documentação



Também foram utilizadas branches e Pull Requests para organizar as alterações.



\## Pull Request



As melhorias finais foram desenvolvidas na branch:



`feature/melhorias-finais`



Depois foram revisadas e integradas à branch principal `main` por meio de um Pull Request.
